# Retail-Sales-Analysis
Retail Sales Analysis using Python, SQL, and Power BI. Analyzed 4,310 rows and 21 columns to identify sales trends, top-performing product categories, customer behavior, and business insights through data cleaning, SQL queries, and interactive dashboards.

**🛠️ Tools & Technologies**
Python: Data cleaning and exploratory data analysis.
SQL: Data querying and business insights.
Power BI: Interactive dashboards and data visualization.

**🎯 Key Finding**
The Electronics category generated the highest sales revenue among all product categories.
📈 Project Outcome
Transformed raw retail data into meaningful insights through data cleaning, SQL analysis, and interactive Power BI visualizations.
